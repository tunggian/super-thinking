# Scenario Analysis

## R — 原文 (Reading)
> Scenario analysis (also known as *scenario planning*) is a method for thinking about possible futures more deeply. It gets its name because it involves *analyzing* different *scenarios* that might unfold. That sounds simple enough, but it is deceptively complicated in practice.

## I — 方法论骨架 (Interpretation)
情景分析是一种有结构的"想象未来"的方法。人们常常犯的错误是只设想一种未来——通常是当前趋势的直线外推——然后为它做准备。情景分析强制你设想多个有实质差异的未来情景，从而暴露未知的未知（unknown unknowns）。技术手段包括：列出可能发生的重大事件（市场崩盘、监管变化、行业并购等），追溯它们对你处境的影响；使用思想实验（thought experiments）探索"如果X发生了会怎样"；以及用反事实思维（counterfactual thinking）想象"如果我当时做了不同选择，现在会怎样"。优秀的预测者（superforecasters）的特点是开放心态、持续修正预测、以及在团队中工作但避免群体思维。

## A1 — 书中的应用 (Past Application)
- 大型企业和政府设有专门的情景分析团队，不断撰写关于未来世界可能样貌的报告，评估公民或股东在不同情景下的处境。
- 作者以职业转换为例：你可以用情景分析来设想不同职业未来的多种可能展开方式，然后用决策树或成本效益分析对最有希望的路径进行定量评估。

## A2 — 触发场景 (Future Trigger) ★
1. 做年度战略规划时，构建2-3个高度差异化的未来情景，测试当前策略的稳健性
2. 面对人生重大决策（换工作、搬家、创业）时，设想三种不同的未来展开路径
3. 在项目启动前做预尸检（pre-mortem）——想象项目已失败，追问"是什么导致了失败？"

语言信号: "如果...将会怎样？", "最坏的情况是...", "我们有没有想过...的可能性？"

## E — 可执行步骤 (Execution)
1. **发散去想** - 使用发散思维（divergent thinking）：列出可能影响你处境的所有重大外部事件，每个成员独立头脑风暴
2. **构架情景** - 选择2-4个差异大且合理的情景，描述每个情景下的因果链和时间线
3. **收敛和行动** - 使用收敛思维（convergent thinking）：对每个情景设计应对措施，找到跨情景的稳健策略

## B — 边界 (Boundary) ★
- 群体思维（groupthink）是情景分析的头号杀手——必须通过独立创作、分组讨论、以及引入外部多元观点来防范
- 情景分析不能消除不确定性，只能提高你对不确定性的准备程度
- 过度重视极端情景可能导致资源浪费在极低概率事件上——需结合预测市场的概率估计来平衡
- 反事实思维用于过去决策时要警惕蝴蝶效应——改变一件事，其他事情不可能保持不变
