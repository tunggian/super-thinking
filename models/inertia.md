# Inertia (惯性)

## R — 原文 (Reading)
> "An object at rest stays at rest and an object in motion stays in motion with the same speed and in the same direction unless acted upon by an unbalanced force." — Newton's First Law

## I — 方法论骨架 (Interpretation)
惯性来自牛顿第一运动定律，在物理之外被用作描述"对变化的抵抗"的隐喻。任何系统——个人信念、组织策略、社会规范——都有惯性。

**个人层面**：信念惯性来自确认偏见和相关模型。你持有的核心政治、宗教和社会信念很可能可以追溯到你的童年和地域文化——你是否最近重新审视过它们？惯性越大，改变信念越难，适应新环境的可能性越低。

**组织层面**：长期战略承诺产生"策略税"（Strategy Tax）——战略本身迫使你做出次优决策。书中举例：Google是全球最大的广告追踪公司，因此它的Chrome浏览器不会添加显著的隐私保护功能——这就是其广告策略的策略税。1990年代，老布什的"Read my lips: no new taxes"承诺后来让他在经济衰退中陷入困境，食言付出了连任失败的代价。

**关键教训**：尽可能避免将策略锁定为不可更改的长期承诺，因为环境变化很快。高惯性的东西即使到达峰值后，下降也非常缓慢——如传真机、录像带出租店、拨号上网仍有残存用户。

## A1 — 书中的应用 (Past Application)
1. Google的Chrome浏览器不添加隐私保护功能——这是其广告主导战略的"策略税"
2. 老布什"Read my lips: no new taxes"→经济衰退中被迫食言→连任失败
3. T-Rex长羽毛、蛋黄是健康食品的认知更新——旧信念的惯性让即使知道真相的人也很难改变习惯

## A2 — 触发场景 (Future Trigger) ★
1. 用户说"公司一直这么做的"，需要挑战僵化的流程或思维
2. 用户试图推动变革但遭遇强烈抵抗，需要理解阻力来源

语言信号: "一直是这样", "以前就这么做", "改不了的", "大家都习惯了"

## E — 可执行步骤 (Execution)
1. **识别惯性来源** - 是信念惯性？利益惯性？流程惯性？不同来源需要不同策略
2. **寻找催化剂降低激活能** - 用数据（如成功案例）反驳反对意见，寻找有动力的人（潜在能量）
3. **创建强制函数** - 用定期会议、日程安排等机制作为催化剂，降低启动变革的门槛

## B — 边界 (Boundary) ★
- 惯性不总是坏的——成熟的流程和根深蒂固的信任是组织价值的重要来源
- 高惯性系统的改变极其耗时——不要期望快速见效
- 有时候绕开惯性（建立新团队/新流程）比正面对抗更有效
